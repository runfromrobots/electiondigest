How the score works

  1. +1 for each race a nonpartisan rater moves toward Democrats.
  2. −1 for each race moved toward Republicans.
  3. One point per race, however many notches it moves. Solid R to Likely R counts the same as Lean R to Toss-up.
  4. Raters that count: Cook Political Report, Sabato's Crystal Ball and Inside Elections. Confirmed changes only.
  5. Never counted: polls, fundraising, endorsements, the generic ballot, forecast odds or court rulings.
  6. No double counting. A second rater making the same move on the same race adds nothing. Moves found late are scored on the day they surface, so batches arrive in lumps.
